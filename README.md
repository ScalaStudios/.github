# Scala Studios `.github`

This repository holds the public organization profile and the default community-health files for [Scala Studios](https://github.com/ScalaStudios).

The profile people see on the organization page is [`profile/README.md`](profile/README.md).

`CONTRIBUTING.md` and `SECURITY.md` in this repository apply only to Scala Studios repositories that do not already define their own file of that name. A copy inside a project repository always wins.
