# Scala Studios `.github`

This repository holds the public organization profile and the default community-health files for [Scala Studios](https://github.com/ScalaStudios).

The profile people see on the organization page is [`profile/README.md`](profile/README.md). Its artwork is in [`assets/profile`](assets/profile). Images that follow the GitHub theme come in `-light` and `-dark` pairs that the profile switches between with `<picture>`, and the two files of a pair differ only in their colours. Colours and type follow Halo's design tokens. `social.png` is the social preview for the repository settings, rendered from `social.svg`.

`CONTRIBUTING.md` and `SECURITY.md` in this repository apply only to Scala Studios repositories that do not already define their own file of that name. A copy inside a project repository always wins.
